# Landing Page Mobile First — O Segredo dos Pipoqueiros

Projeto em HTML, CSS, JavaScript e Python, com foco em mobile e alta conversão.

## Como abrir

Abra `index.html` diretamente no navegador ou rode:

```bash
python app.py
```

Acesse: `http://localhost:8000`

## Onde trocar o link de pagamento

No arquivo `index.html`, procure por:

```html
https://pay.kiwify.com.br/SEU-LINK-AQUI
```

Substitua pelo link real do checkout.

## Estrutura

- `index.html` — estrutura da landing page
- `styles.css` — identidade visual e responsividade
- `script.js` — menu mobile, FAQ, scroll suave e CTA sticky
- `app.py` — servidor local em Python
- `assets/` — imagens e ícones locais

## Identidade visual

Paleta alinhada ao produto principal:

- Vinho escuro
- Dourado
- Creme
- Branco quente
- Ícones simples e diretos
- Layout mobile-first
