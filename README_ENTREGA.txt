O SEGREDO DOS PIPOQUEIROS - LANDING PAGE MOBILE-FIRST

Como testar localmente:
1. Extraia o arquivo compactado.
2. Abra a pasta do projeto no terminal.
3. Rode: python app.py
4. Acesse: http://localhost:8000

Arquivos principais:
- index.html
- styles.css
- script.js
- app.py
- assets/ imagens WebP e favicon
- referencia/mockup-referencia.png

Link de pagamento:
No index.html, troque SEU-LINK-AQUI pelo link real do checkout.
